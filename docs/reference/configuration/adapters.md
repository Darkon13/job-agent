# `adapters`

Инстансы платформ. Каждый профиль ссылается на adapter по `tag`; настройки
платформы живут в `settings` и валидируются самим адаптером.

## Пример

```json
"adapters": [
  {
    "tag": "hh-main",
    "type": "hh",
    "settings": {"api_delay_ms": 250}
  }
]
```

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `tag` | string | **да** | Уникальное имя инстанса. На него ссылаются `profiles[].adapter` и `searches[].adapter`. |
| `type` | string | **да** | Тип платформы. Сейчас поддерживается `hh` (HeadHunter). |
| `settings` | object | нет | Настройки конкретного адаптера. Формат определяется `type`; неизвестные поля отклоняются. |

## `settings` для `hh`

| Поле | Тип | Обяз. | По умолчанию | Описание |
|---|---|---|---|---|
| `api_delay_ms` | number | нет | `0` | Минимальная пауза между последовательными API-запросами одного профиля, миллисекунды. Полезно при 429 от api.hh.ru. |
| `user_agent` | string | нет | `job-agent/0.1 (local installation)` | User-Agent прямых HTTP-запросов адаптера: API (`HH-User-Agent`), поднятие и публикация резюме, действия с переговорами (`decline`/`trash`). Страницы в browser-worker открывает сам Chromium со своим UA, поэтому значение влияет только на обращения без браузера. Можно указать любой строкой: обычный Chrome-UA (как в примере), собственный с контактом (`JobAgent/1.0 (you@example.com)`) или оставить пустым — тогда используется встроенный. Меняйте только при необходимости и не подменяйте реальный контакт в API-запросах, если платформа просит обратную связь. |

## Транспорты

Один adapter-инстанс обслуживает все профили и сам выбирает транспорт:

- **OAuth/API** — если у профиля задан `credentials_ref`;
- **browser session** — если задан `state_file`; используется для browser-only
  операций (поиск по web-выдаче, анкеты, чаты, skill verification);
- при наличии обоих transport выбирается API-first, а browser — по политике
  операции и категории ошибки (`Unsupported`).

Profile-scoped состояние (резюме, чаты, сессии) не хранится в adapter:
он получает его из профиля при биндинге.
