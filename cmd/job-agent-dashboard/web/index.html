Автоматизация

Пользовательские джобы из конфигурации и системные (снятие состояния HH, обновление сессии, перепроверка анкет) срабатывают по cron или таймеру, либо вручную. Нажмите на строку джобы, чтобы раскрыть её: там профили, описание и точечные действия — запуск и пауза для каждого профиля отдельно. Счётчик у названия показывает активные профили из привязанных. Пользовательские джобы можно ставить на паузу целиком или по одному профилю; системные ставит на паузу сам сервис (например, при разлогине) — у оператора остаётся только снять её.
